# Contributing to BonkWeb

This repository is published for viewing only, but fixes and suggestions are welcome. Issues and pull requests may
be written in English or French.

- Open an issue first for anything beyond a small fix.
- One logical change per pull request. Commits follow Conventional Commits, in lower case, with a scope:
  `fix(site): correct the download link`.
- Keep pure black on white, with no external resources: the tests check the contrast and the security policy blocks
  anything else.
- Before submitting, in `Bonkosapp/`: `pnpm install`, `pnpm lint`, `pnpm test`, `pnpm build`.
- Say what you tested, and what you could not.
- By submitting a contribution, you confirm that it is your own work and you grant the copyright holder a perpetual,
  worldwide, royalty-free license to use, modify and publish it as part of this website.

Security issues: do not open a public issue, write to security@bonk-os.app.
